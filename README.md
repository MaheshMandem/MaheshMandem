## 🏦 About Me

- 💼 **Software Engineer at Intellect Design Arena — iGTB** (Global Transaction Banking), working on enterprise banking software used by financial institutions
- ⚙️ I build **backend services in Java & Spring Boot** — REST APIs, microservices, event-driven flows with **Kafka**, caching with **Redis**, and data on **Oracle SQL / PostgreSQL**
- 🎯 I care about what matters in money movement: **correctness, idempotency, auditability, low latency and high throughput**
- 🚀 Currently building **[FinOpsX](https://github.com/MaheshMandem/Finopsx)** — a microservices-based fintech platform, starting with a payment service
- 🤝 Open to **Backend / Java / Fintech engineering** opportunities

## 🚀 Featured Project

### [FinOpsX — Fintech Microservices Platform](https://github.com/MaheshMandem/Finopsx)

A hands-on fintech platform built the way banks build systems: independent Spring Boot microservices, event-driven communication over Kafka, Redis caching, PostgreSQL persistence and secured APIs.

`Java 17` `Spring Boot 3` `Spring Security` `Kafka` `Redis` `PostgreSQL` `JPA` `Actuator`

- 💳 **Payment Service** — payment initiation and status APIs *(in progress)*
- 📨 Event publishing to Kafka for downstream services (ledger, notifications)
- ⚡ Redis caching for fast status lookups
- 🔐 Secured endpoints with Spring Security
